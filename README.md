# flask-ap
## 概要
学習目的で作成したWebアプリケーションです。<br>
CRUD操作が可能な簡易画像データ管理システムです。<br>
Flaskを使用したバックエンドとMySQLを使用したデータベースを基盤として構築しています。<br>

---

## 主な機能

- **データの追加**
　タイトル、画像データを入力してデータを追加します。

- **データの表示**
　一覧画面で登録されたデータを確認できます。<br>
また、登録時の日次やアップデート時の日時の詳細を閲覧が可能です。

- **データの更新**
　各データに対して、個別に情報を更新することが可能です。

- **データの削除**
　不要になったデータを削除できます。

---

## 使用技術

- **バックエンド**：Flask

- **データベース**：MySQL

- **テンプレートエンジン**：Jinja2

- **環境管理**：Poetry

- **バージョン管理**：Git/GitHub
